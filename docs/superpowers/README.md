# Superpowers Design Records

This directory contains dated specs and implementation plans.

They are historical design records, not the default source of current operating
truth. Use them for rationale, tradeoffs, and implementation history. When a
dated record disagrees with current code, tests, or current docs, prefer the
current source unless the task is explicitly to investigate or update that
record.

For current agent guidance, start with:

- [`../agent-development.md`](../agent-development.md) when changing Clodsite.
- [`../agent-authoring.md`](../agent-authoring.md) when using Clodsite to build
  or modify a site.
